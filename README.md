# Cisco Network Infrastructure Lab

## Sobre o projeto

Este projeto consiste na reprodução de uma infraestrutura de rede corporativa baseada em um ambiente real no qual trabalhei e atuei na administração e sustentação da infraestrutura de TI.

O objetivo é revisitar a arquitetura, os equipamentos, as conexões e as configurações utilizadas, consolidando conhecimentos técnicos e documentando a estrutura por meio do Cisco Packet Tracer.

## Arquitetura

O laboratório representa uma infraestrutura corporativa com:

- Core Switches (Core A e Core B)
- Switches ToR (Top of Rack)
- Switches de distribuição
- Segmentação de rede com VLANs
- Redundância de links e equipamentos
- Infraestrutura de servidores
- Telefonia IP
- Interconexão entre unidades

## Tecnologias e conceitos

- Cisco Packet Tracer
- Switching e Routing
- VLAN e Trunk
- STP
- EtherChannel
- TCP/IP
- Redundância e alta disponibilidade
- Arquitetura de redes corporativas

## Objetivo

Utilizar a simulação como ferramenta de revisão técnica, documentação e aprimoramento de conhecimentos em infraestrutura de redes corporativas.
